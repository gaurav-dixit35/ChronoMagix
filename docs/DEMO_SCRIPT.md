# Demo recording script

Record a clean browser window at desktop width, then repeat the key schedule screens at phone width. Do not expose real database credentials or private environment files.

1. Sign in as `admin@chronomagix.com` (`Admin@123`) and show the course catalog and instructor list.
2. Create a course with a short description and a JPEG, PNG or WebP cover. Show the preview and resulting detail page.
3. Add a lecture. Choose a date first, show busy instructors disabled and available instructors selectable, then save.
4. Show the new lecture and the updated instructor availability. Demonstrate a duplicate assignment rejection through a direct API request or a second attempted booking.
5. Change a lecture date, delete a lecture, then delete a temporary demonstration course and show that its lectures are removed.
6. Sign in as `rahul@chronomagix.com` (`Instructor@123`), show the personal schedule, and demonstrate that an admin URL redirects away.
7. Show the lectures table and week view, then the responsive navigation and schedule on a narrow viewport.
